# What’s the difference between a JSON object and a Python dictionary?
A JSON object lives within a .json file while a Python dictionary lives in memory while a program is running. A JSON object can live between program runs, while a Python dictionary can't (unless it's written to storage similar to how a json file is)

# Looking at the Wikipedia article, what types of data can be represented in JSON?
JSON supports numbers, strings, booleans, arrays, objects, and null
