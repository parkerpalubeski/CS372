# Describe the type of problem using threads would solve.
Since so many networking functions block while waiting for some incoming connection, data or something else, multithreading allow us to run other parts of the program while another part of the program is waiting.

# What’s the difference between a daemon and non-daemon thread in Python?
A daemon thread is an infinitely looping thread. It is killed immediately upon all the non-daemon threads exiting.

# What do you have to do to create the main thread in Python, if anything?
The main thread is the default thread. All you need to do is create a program and run it.
