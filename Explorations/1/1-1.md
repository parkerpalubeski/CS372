# CS 372 - Exploration 1.1: Intro to Sockets API

## What role does bind() play on the server side?
>bind() ties a socket to a port, so information that enters a certain port is routed to that socket.

## Would a client ever call bind()? (Might have to search this one on the Internet.)
> There are some instances where this might happen, but this is rare and abnormal. This may happen when conducting certain forms of network testing, or when one wants to force a connection through a certain network adapter (like a wi-fi card instead of an ethernet card). However for ordinary use this would never happen.

## Speculate on why accept() returns a new socket as opposed to just reusing the one we called listen() with.
>Because that would require changing the listen socket to the newly assigned duty. However the listen socket needs to keep listening, so it instead creates a new socket and assigns that socket the new duty and goes back to listening. This way the server can handle requests from multiple clients concurrently.

## What would happen if the server didn’t loop to another accept() call? What would happen when a second client tried to connect?
>If a second client tries to connect, the socket will be created with the OS, be bound to a port, and the client will seemingly receive notice that their connection was successful, but data exchange won't occur because the server didn't accept the socket.

## If one computer is using TCP port 3490, can another computer use port 3490?
>Yes, because ports are local to a computer. They are distinguished by their IP address, not the ports they have.

## Speculate about why ports exist. What functionality do they make possible that plain IP addresses do not?
>I would assume the primary function is to allow multiple connected programs to run at once on the same device. Additionally, I suppose that ports may also serve a purpose of providing a kind of abstraction for certain security measures.  e.g. I might assign a program that needs certain security measures on a specific range of ports (say 1000-2000) because I know those ports have greater or lesser firewall protections. I would assume different ports also have similar benefits for volume and even type of traffic.
