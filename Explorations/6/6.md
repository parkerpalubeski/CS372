### What’s the deal with frames versus packets in Ethernet? Where in the ISO OSI network stack do they live?
Frames are created at the data link layer, while packetrs are created at the network layer. Packet creation is essentially the wrapping that tacks on the IP header, and Frame creation tacks on the ethernet header. Frames are for localized routing *within* a network.

### What’s the difference between a byte and an octet?
An octet is strictly 8 bits, whereas a byte *could* be less or more (although traditional computer architecture almost always means they're 8). Octet is simply less ambiguous, even if arguably unnecessary today.

### What’s the main difference between CSMA/CD and CSMA/CA?
CD detects collisions by validating the data sent back and forth. It then orders other devices to halt so it can transmit. CA is for Wifi, and it uses random timing and then tries again. 

### Describe the problem ARP is solving.
Once packets reach the destination's local network, it doesn't know which machine to go to. ARP helps it by retrieving the MAC address of the destination and sending it there.

### Why do entries in ARP caches have to expire?
ARP cache entries expire because MAC addresses, and the devices assigned to certain IP addresses, can constantly change. This could cause traffic to be directed tot he wrong device if it isn't refreshed.

### Why can’t IPv6 use ARP?
IPv6 has its own version of the protocol, that supports the longer addresses of IPv6.
