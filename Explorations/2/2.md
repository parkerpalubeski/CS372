## How many times more IPv6 addresses are there than IPv4 addresses?

IPv4 has $2^{32}$ addresses, whereas IPv6 has $2^{128}$ 

So IPv6 has $2^{96}$ times more IP addresses.

## Applications commonly also implement their own encryption (e.g. ssh or web browsers with HTTPS). Speculate on the advantages or disadvantages for having IPSec at the Internet layer instead of doing encryption at the Application layer.

Application-level encryption seems like it would be most effective at protecting your data in transit. That way, an uninvolved party (not client or server) won't have eyes into the data you're sending, or at least it would look like garbage data. 

According to what I've researched however, Application-layer encryption doesn't encrypt headers, which means that a lot of metadata including who is *receiving* and who is *sending* is still available to third parties that wished to intercept the data (e.g. a government, a snooping boss, ISP, etc.). 

An IP-layer encryption would encrypt both the data *and* the metadata. However, if you are using a third-party IP-layer encryption, they would still be able to read the data because they have the tools to do so. 

The most secure way to transmit data appears to be a dual system that employs both application-level and IP-level encryption, while reducing third-party involvement and using proprietary software and infrastructure wherever possible.

## If subnet reserved 5 bits to identify hosts, how many hosts can it support? Don’t forget that all-zero-bits and all-one-bits for the host are reserved.

$2^5 - 2 = 30$

The subnet can support 30 hosts assuming $11111$ and $00000$ are reserved.

## What is the benefit to having a static IP? How does it relate to DNS?

Static IPs seem to be more useful for servers whereas Clients seem to be a more typical use case for dynamic IPs. 

Having a server whose IP address is unchanging is a major benefit for DNS. Browsers will consult the cache first to convert a Domain name to an IP address, so if the IP address never changes, subsequent connections will be much faster because it doesn't have to send out a DNS request.

## 192.168.262.12 is not a valid IP address. Why?

262 is above 255 which is the maximum value for each period-separated part of an IPv4 address. And since it isn't in hex, it isn't an IPv6 address either.

## Reflect on some of the advantages of the subnet concept as a way of dividing the global address space.

Subnetting is likely more efficient for routing than a non-subnetted network because a routing table wouldn't need to store routing information for every computer on the globe in early stages. All the IP layer needs to know is "I need to go to this subnet" up until the moment it reaches that subnet, where it can then search that subnet for subnets within it, or go to the IP of the client.

After researching this, I found that the global internet is divided into five "RIRs" (regional internet registries):

* ARIN - North America
* RIPE NCC - Much of western eurasia
* AFRINIC - Africa
* APNIC - Asia-pacific
* LACNIC - Latin America

These can sort of be thought of at the very top of a subnet tree. Usually, these are divided into subnets assigned to various entities like ISPs, Cloud providers, Banks, etc.

It's kind of like having a hierarchical database of IPs, versus a single $2^{128}$ long array of all of the IP addresses on the globe. Search would be far more efficient in the former case than the latter.

## What are some benefits of IPv6 over IPv4?

IPv6 provides the following benefits, among others:

* More IP addresses, so the number is much harder (and probably physically impossible) to exhaust. 
* Each device can also get a unique IP address instead of one for an entire network
